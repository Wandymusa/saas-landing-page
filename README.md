# NexusAI — B2B SaaS Command Center Landing Page

A high-converting, responsive landing page engineered for an enterprise SaaS platform. Built with React, Vite, and Tailwind CSS, featuring modern UI patterns, real-time pipeline visualizers, and interactive pricing state management.

---

## ⚡ Key Highlights & Architecture

- **Hero & Lead Funnel**: High-conversion hero section featuring dynamic priority-waitlist form validation and responsive call-to-actions.
- **Product Telemetry Preview**: Simulated real-time observability console displaying live throughput, multi-region latency telemetry, and streaming ingestion logs.
- **Bento Feature Grid**: Modular layout detailing SOC2 compliance, pipeline synchronization, and automated reporting capabilities.
- **Interactive Tiered Pricing**: Annual/monthly toggle calculating discounted software license rates with highlighted conversion tiers.
- **Modern Responsive Design**: Accessible dark-mode palette built with modern utility CSS and reactive layouts across mobile, tablet, and widescreen viewports.

---

## 🛠️ Tech Stack

- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Iconography**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)
